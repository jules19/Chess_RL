# Reinforcement Learning Assessment: AlphaZero-Style Chess

**Instructions to learners:** Answer each question in 2-5 sentences. If the material you studied does not teach something needed to answer, write NOT COVERED rather than using outside knowledge.

Questions marked **[Transfer]** describe a situation you have not seen. Reason from principles; there is no single memorised answer.

---

**Q1. The formalism.**
Describe self-play chess as a reinforcement learning problem: what are the states, actions and rewards, when does a reward arrive, and what discount is implied? Then say precisely what quantity the value head is trained to estimate in `play_selfplay_game`: the expected return of *which* policy, from *whose* perspective?

**Q2. Why self-play improves, starting from nothing.**
`run_training_loop` can start from random weights. The network is trained to imitate visit counts from `puct_search`, and that search was guided by the same network. Explain why this imitation can make the network *stronger* rather than just copying itself. Where does genuinely new information about chess enter the system when the network starts out knowing nothing?

**Q3. Value versus policy. [Transfer]**
Inside `puct_search`, the policy head and the value head do different jobs. Describe each job. Then predict what search would do in two broken cases: (a) the policy head is excellent but the value head outputs random noise; (b) the value head is excellent but the policy head is uniform. Which case would you expect to cope better as `simulations` grows, and why?

**Q4. Exploration.**
Self-play uses two exploration mechanisms: Dirichlet noise on the root priors (`add_root_noise`) and temperature-based move selection for the first `temperature_moves` plies. Explain what failure each one prevents and why one mechanism does not make the other unnecessary. Also explain why the arena (`play_arena_game`) turns both off.

**Q5. Bootstrapping versus Monte Carlo. [Transfer]**
The value targets stored by `play_selfplay_game` are final game outcomes, but the backups inside `puct_search` use the network's own value estimate at each leaf. Classify each one as a Monte Carlo or a bootstrapped estimate, and compare their bias and variance. Suppose someone proposes replacing the game-outcome target with the search's root value estimate (the root Q). What would that gain, and what specific risk would it carry early in training?

**Q6. Off-policy data.**
The replay buffer holds positions generated by earlier champions, with moves chosen under root noise and temperature. Is the *value* target in the buffer an unbiased estimate of the current network's value? Is the *policy* target affected by the same problem in the same way? Explain why AlphaZero can get away with no importance-sampling correction, and what `buffer_capacity` trades off.

**Q7. Stability with function approximation.**
In this loop the network produces the data it is later trained on, so the training distribution moves whenever the network changes. Name two distinct ways this feedback could make learning unstable or make it collapse. For each, identify a mechanism in the code (for example in `ReplayBuffer`, `train_candidate` or `run_training_loop`) that dampens it, and explain *how* it dampens it.

**Q8. Credit assignment.**
`play_selfplay_game` labels every position in a game with the final result. So a blunder by the eventual winner at move 30 gets a target of +1 for the winner. Explain why this still produces a useful value function, what it costs, and which other part of the AlphaZero pipeline gives move-level credit that the outcome label cannot.

**Q9. Evaluating agents. [Transfer]**
By default `run_training_loop` promotes a candidate if it scores more than 0.55 over `arena_games=6`. (a) Roughly how likely is it that a candidate of *exactly equal* strength gets promoted, and what does that tell you about the gate? (b) Why is a falling training loss not evidence that the agent got stronger in this setting? (c) Suppose candidates keep beating their predecessors but you suspect the engine is not actually improving. Design an evaluation that would show it.

**Q10. Truncation. [Transfer]**
Someone sets `max_moves=40` in self-play to make games faster, so most games hit the cap and are scored as draws. Explain what this does to the value targets and to what the agent learns. Explain also why the cap creates a mismatch with the state the network sees (consider what the network would need to know to predict the outcome correctly), and suggest a principled fix.
