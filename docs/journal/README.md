# Project journal

These are the day-by-day logs, plans and result write-ups produced while the project was built
(November 2025). They record **how** the project got here, including plans that changed and
estimates that were never measured. Read them as history, not as lessons.

To learn how the engine works, start at [`LEARN.md`](../../LEARN.md).

`build_complete_tutorial.py` is also kept here as history: it was the start of a generator for
`chess_rl_complete_tutorial.html`, but it never writes anything (it only prints a message). The HTML
file itself is the source of truth.
