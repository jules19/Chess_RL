# Project history (archive)

These files record how the project was built: the day-by-day development
diary, the changelog, and the HTML tutorials the course replaced. They are
kept for the record, **not as course material**. Their Elo figures are
self-estimates that were never measured, some describe code that has since
changed, and some refer to the folder `test/`, which is now `experiments/`.

To learn from this project, start at [the course](../../course/README.md).
